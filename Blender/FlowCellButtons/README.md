User-facing clickable wrappers live here.

FlowTest generates or updates these `.ps1` wrappers from Blender config/action state. They are not the shareable source-of-truth tool files; downloadable/public `.py` tools belong in `Blender\Blender Scripts`, managed installed source copies belong in `Blender\Blender Active Scripts`, and the bridge-managed runtime sources live under `ManagedActions`.

Use the Codex prompt and short Add Button contract in [docs/blender-buttons.md](..\..\docs\blender-buttons.md).
