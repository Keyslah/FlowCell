User-facing clickable wrappers live here.

FlowTest generates or updates these `.ps1` wrappers from Blender config/action state. They are not the shareable source-of-truth tool files; downloadable/public `.py` tools belong in `Blender/ScriptBank`, and installed action sources belong in `Blender/ManagedActions`.

Use the Codex prompt and short Add Button contract in [docs/blender-buttons.md](..\..\docs\blender-buttons.md).
