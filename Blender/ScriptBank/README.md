# Blender ScriptBank

Community-submitted Blender scripts can be placed here for GitHub sharing, review, and later installation through FlowTest `Add Button` when appropriate.

Use this folder for downloadable `.py` tools, example tool sets, and review-stage files that should sync through GitHub but are not yet installed as active FlowCell Blender buttons.

Installed action sources belong in `Blender/ManagedActions`.
Active clickable wrappers belong in `Blender/FlowCellButtons`.
