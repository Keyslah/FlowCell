# Blender Scripts

This is the public downloadable Blender script library.

- Put shareable `.py` source files and folder bundles here.
- `Add Button` can install files or folders from anywhere, but this is the default repo library location.
- Panel-named folders here are live Blender panel exports made of real Add Script-ready `.py` source files.
- `panel-add-script-manifest.json` records which live Blender button each exported file came from and whether it was copied from source or generated as a bridge-ready wrapper.
- Inline FlowTest tool surfaces such as `alignment tools` and `flatten revolve` export the underlying default action-capable `.py` source, not the special FlowTest inline UI shell.
- Installed managed copies belong in `Blender\Blender Active Scripts`.
- Live runnable wrappers still belong in `Blender\FlowCellButtons`.
