Per-button PowerShell wrappers have been purged.

Blender script buttons now run through direct bridge metadata (`bridgeAction` plus optional `bridgeData`) from the panel records. Shareable/public `.py` source tools belong in `Blender\Blender Git Scripts`; generated installed runtime copies live under `ManagedActions` and are registered through `flowcell_custom_actions.json`.

Use the Codex prompt and short Add Script contract in [docs/blender-scripts.md](../../../docs/blender-scripts.md).
