# Blender Addons - Copy contents Into Blender

This folder is the paste-ready FlowCell Blender add-ons bundle for fresh setup or repair.

If Blender already has the FlowCell add-on enabled and working, you do not need to copy this bundle again.

When you do need to install or repair it, copy this folder's contents directly into Blender's user add-ons folder:

`%APPDATA%\Blender Foundation\Blender\<Blender version>\scripts\addons`

After copying, Blender's `scripts\addons` folder should contain these FlowCell items:

- `flowcell_actions.py`
- `flowcell_bridge.py`
- `blender_bridge_flowcell\`

Do not treat this folder as a public downloadable tool source area. Shareable tool files belong in `Blender\Blender Git Scripts`; durable private copies belong in `Blender\Blender Local Scripts`, and panel-local runnable copies belong under `Blender\Panels`.
