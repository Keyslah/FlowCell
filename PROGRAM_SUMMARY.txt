FlowCell Program Summary
Last updated: 2026-06-21

Purpose
-------
FlowCell is the desktop frontend, command host, program folders, local runtime state, and Blender bridge workflow.

Current frontend state
----------------------
- Dynamic Organization now has a role-based engine under `Programs\Windows\SupportScripts\Dynamic-OrganizationCore.ps1`, runnable Windows Files panel and Git Scripts wrappers, and frontend resolver/types under `FlowCellFrontend\src\features\organization`. Roles are destinations/purposes and can exist without file types; optional file types are used only for loose-file cleanup. Button output resolves directly by output role, `unknown` / `Unknown Files` is the preset catch-all for unmatched loose files, and ambiguous loose files whose extension matches multiple roles are reported instead of guessed. `docs\dynamic-organization.md` and `docs\dynamic-organization-profile.example.json` document the profile shape and current backend behavior.
- Normal repository startup runs `FlowCell\helpers\Start-FlowCellPreflight.ps1` before reusing, building, or starting the frontend. Missing or failed preflight stops both normal and portable startup, core Windows registration failures propagate instead of opening FlowCell without Windows, and successful runs write a completion marker to `FlowCell\local\logs\startup-preflight.log`.

Keep this summary updated whenever FlowCell behavior changes.
