FlowCell Program Summary
Last updated: 2026-06-21

Purpose
-------
FlowCell is the desktop frontend, command host, program folders, local runtime state, and Blender bridge workflow.

Current frontend state
----------------------
- Dynamic Organization has a role-based backend and frontend resolver. Setup Organization opens the managed `organization-setup` Tauri/React window by intercepting the panel script filename, while the full PowerShell setup UI remains available as a standalone fallback; its Project Tree is a full-height left rail and the right column uses one horizontal row with equal Role and File Types inputs, followed only by roles assigned to the selected folder. The old unresolved-loose-files panel and inline Unknown warnings are removed; missing Unknown assignment uses one warning popup. The preset `unknown` role must be assigned to a scanned project folder before saving; unmatched loose files fall back to `unknown`, while files matching multiple roles open a scoped file/run/project choice prompt.
- Normal repository startup runs `FlowCell\helpers\Start-FlowCellPreflight.ps1` before reusing, building, or starting the frontend. Missing or failed preflight stops both normal and portable startup, core Windows registration failures propagate instead of opening FlowCell without Windows, and successful runs write a completion marker to `FlowCell\local\logs\startup-preflight.log`.

Keep this summary updated whenever FlowCell behavior changes.
